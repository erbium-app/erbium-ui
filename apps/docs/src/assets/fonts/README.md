# Cal Sans

Cal Sans 2.0 variable fonts, reused from coss UI’s shared fonts to match its documentation typography.

Upstream: https://github.com/calcom/sans

The unmodified normal and italic WOFF2 files are licensed under the SIL Open Font License 1.1; see [OFL.txt](./OFL.txt). Astro’s local font provider serves these files and generates font metrics and fallback styles.
