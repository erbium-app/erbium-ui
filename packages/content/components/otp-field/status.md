Pass TanStack Form's `field.state.meta` as `validation`. `isValidating` applies the shared Skeleton sweep to the slots using Skeleton’s default neutral colors,
a touched invalid value shows an error. Success appears only when the current complete
value matches `verifiedValue`, which the demo sets after verification finishes.
Validation keeps editing enabled. This demo uses `onChangeAsync` to check every complete
changed code, including corrections made while a previous check is pending. Demo code: 123456.

Incomplete values clear verification feedback without checking the code. Verification starts only when all six digits are present.
