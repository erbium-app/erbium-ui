title: "Nested options"
story: NestedOptions
---

Option fields whose options form a tree. Area groups product areas (Platform opens API, which opens REST and GraphQL) and Assignee groups people by team. Each group opens in place in the same menu, with a back button and the group's name. The search finds options at any depth and shows the path to each one. Only options without children are chosen, so the items hold leaf values.
