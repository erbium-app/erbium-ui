Chip mode on a TanStack table. Add a filter from the searchable menu: option fields open their options in place, in the same menu, with counts, and text, number and date fields open their editor in a new chip. Area is an option tree, so its groups open level by level. The search finds fields and options at any depth. Change a chip's operator or value in place.
