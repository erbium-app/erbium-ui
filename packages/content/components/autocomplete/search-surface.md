---
title: "Search surface"
description: "A flush search header for an inline result panel."
---

Search a set of documents inside a panel. The search row is flush with the surrounding surface and separated from the results by a full-width separator. Use this pattern for inline search; use AutocompleteInput when the input is a standalone form field. Use Command when choosing a result executes an application action.

The longer document list demonstrates the thin product scrollbar. Scroll results while the flush search header remains fixed; filtering reduces the list and removes the scrollbar when it is no longer needed.
