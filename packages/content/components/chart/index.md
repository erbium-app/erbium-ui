## Usage

Charts use [TanStack Charts](https://tanstack.com/charts) definitions. Import `Chart` from `@erbium/ui/components/chart`, then create marks and scales with `@tanstack/charts`. Define colors, axes, grid, focus, tooltip, and legend in the chart definition. Set a height and an accessible label on each chart. See the example stories for working compositions.
