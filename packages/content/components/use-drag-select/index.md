Selects or clears neighboring items with a pointer drag. The example uses joined selection items with checkbox and keyboard support.

Import `useDragSelect` from `@erbium/ui/hooks/use-drag-select`. Supply `resolve` and `selectRange` callbacks and spread its handlers on the containing element.
