title: "Steps"
story: Steps
---

Pass `steps` to allow only a fixed set of values, including uneven intervals. Each value sits at its position on the scale, thumbs snap to the nearest one while dragging, and arrow keys move one allowed value per press (ten with Shift or Page Up/Down). Home and End jump to the first and last value. `steps` replaces `min`, `max` and `step`.
