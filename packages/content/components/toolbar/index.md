## Usage

A labeled command bar with arrow-key navigation. `ToolbarButton` and `ToolbarLink` use the shared button styles; compose toggles or popup triggers with the button’s `render` prop. In a horizontal toolbar, put an input last so arrow keys still work for text editing.

**Import:** `@erbium/ui/components/toolbar`
