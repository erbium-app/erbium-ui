A sign-up form owned by TanStack Form. One Effect Schema checks the email, requires 8 characters and a number in the password, and adds a filter that places a mismatch on the confirmation through its `path`. Each password renders through `field.PasswordField`. Showing a password with the pointer keeps focus in the input, so it does not mark the field touched. Submitting hides both passwords again.
