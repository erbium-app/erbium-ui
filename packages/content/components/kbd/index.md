Displays a platform-aware shortcut. Pass the stored binding to `hotkey`; TanStack Hotkeys formats it for macOS, Windows, or Linux.

**Import:** `@erbium/ui/components/kbd`

```tsx
<Kbd hotkey="Mod+K" />
```
