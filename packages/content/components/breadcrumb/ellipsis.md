---
title: "Collapsed"
story: Ellipsis
---

Adjust the width to see the trail collapse. The ellipsis appears only when there are hidden parent pages. Select a page from the menu to navigate, or press Escape to return focus to the button.

The breadcrumb responds to its own container, so resizing a drawer or panel can change the visible trail without resizing the window. The first link stays visible whenever it fits beside the ellipsis and current page. With more room, the links closest to the current page come back first.
