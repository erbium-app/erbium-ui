---
title: "Searchable"
description: "Filter grouped actions without leaving the menu."
---

Type to filter, use arrow keys to highlight an action, and press Enter to activate it. Escape closes the menu and returns focus to its trigger; opening again starts with an empty query. Clear search restores the full list. Empty groups disappear with their items. The flush search header stays above the scrolling list and uses the same typography, responsive height, and separator as Command.

The folder submenu has an independent query. Search for “Move”, open it, and filter folders without changing the parent search. Checkbox actions keep their usual selection behavior.
