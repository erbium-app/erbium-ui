## External documentation

TanStack Hotkeys supplies platform detection and keyboard shortcut formatting. Register behavior with `useHotkey` from `@tanstack/react-hotkeys` and label it with `Kbd`.

- [TanStack Hotkeys](https://tanstack.com/hotkeys/latest/docs/reference)
