Typography starts with readable body text. Font choice, size, line spacing, and line length work together. Establish a clear hierarchy before adding emphasis. [Practical Typography](https://practicaltypography.com/typography-in-ten-minutes.html) explains these fundamentals. The [Better writing skill](https://skills.sh/jakubkrehel/skills/better-writing) covers clear, concise interface copy.

Erbium shares font roles across its interfaces and documentation. The examples below show them in controls, code, reading content, and multilingual layouts. [**Shadcn Typeset**](https://ui.shadcn.com/docs/typeset) provides the reading styles. Components keep their own text sizes and spacing.
