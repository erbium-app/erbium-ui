Erbium typography uses five text roles across interfaces and Markdown: display, title, subtitle, body, and caption. Cal Sans provides the Latin voice, Vazirmatn handles Arabic-script text, and Paper Mono makes code and identifiers distinct. Hierarchy comes from size, weight, and space.

Start with 16px body text, 14px supporting text, natural tracking, and foreground or muted colors. The examples below show the same defaults in components, reading content, code, and multilingual layouts. Reading presets keep their size across screen widths and add room for Arabic-script marks.
