# Example attribution

Some component examples are adapted from the [shadcn/ui examples](https://github.com/shadcn-ui/ui/tree/main/apps/v4/examples/base). They live alongside other examples in `src/<component>/examples`, organized by component and scenario. Imports use Erbium UI primitives; framework helpers, icons, and services have been adapted for shared React previews.

The original MIT license is preserved in [licenses/shadcn-ui.md](./licenses/shadcn-ui.md).
