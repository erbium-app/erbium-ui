# shadcn/ui examples

These examples were adapted from the [shadcn/ui examples](https://github.com/shadcn-ui/ui/tree/main/apps/v4/examples/base) for the Erbium UI Storybook. Imports use `@erbium/ui/components/*`, and a few examples use local substitutes for framework helpers, icon packages, or backend services.
