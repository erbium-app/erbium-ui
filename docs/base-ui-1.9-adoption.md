## Scope and validation limits

The release also fixes Accordion, Collapsible, Dialog, Alert Dialog, Checkbox, Field, Number Field, OTP Field, Popover, Preview Card, Radio Group, Slider, Switch, Tabs, Toast, and Tooltip internals. These fixes are supplied by the installed dependency; copying them into styled wrappers would create competing behavior. New CssVariables and DataAttributes types are available directly from Base UI when custom styling needs them.

This is a source and API audit, not a claim that every browser regression has been reproduced. Manual checks should cover keyboard filtering and submenu navigation, async result highlighting, rapid query changes, chip-to-input focus, nested overlays, and touch drawers on 120 Hz devices with virtual keyboards. Screen-reader checks should verify loading announcements without announcing an empty-result message during loading.
